A token launch radar: it reads a sealed DefiLlama snapshot of 758 protocols, ranks the 178 pre-token ones — the full 40-protocol watchlist plus 138 early finds below the floor — by an implied value calibrated on the live market's own mcap/TVL ratios, and gives every protocol a concrete farm plan with costs and times, in a static dashboard that renders with no network.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../token-radar-01-kit/input/snapshot.json
```
